## 5. Resident Access to Financial Records

Residents may request a copy of the detailed financial statements by:
1. Visiting the Admin Office with a valid CNIC.
2. Submitting a written request via the portal at **portal.smartsociety.pk → Documents → Financial Reports**.
3. The report will be shared within **5 working days**.
