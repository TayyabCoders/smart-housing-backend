# 🏠 Smart Home Integration Guide

Smart Society supports a fully integrated smart home ecosystem compatible with the Society App. Residents can control utilities, security, and comfort systems from a single platform.

## 1. Compatible Smart Devices

| Device Category | Supported Brands | Integration Method |
| :--- | :--- | :--- |
| Smart Locks | Yale, Schlage, Godrej | Wi-Fi / Zigbee |
| Smart Lighting | Philips Hue, LIFX, Tuya | Wi-Fi / Zigbee |
| Smart Thermostats | Honeywell, Ecobee | Wi-Fi |
| Video Doorbells | Ring, Hikvision, Dahua | Society App Direct |
| Smart Plugs | TP-Link, Sonoff | Wi-Fi |
| Solar Inverters | Growatt, Solis, Solax | Society App API |

## 2. Setting Up Smart Home via Society App

1. Open the **Society App → Smart Home → Add Device**.
2. Scan the device QR code or enter the device serial number.
3. Connect to your home Wi-Fi (2.4 GHz recommended for most IoT devices).
4. Assign the device to a room and name it.
5. Set automation rules (e.g., "Turn off all lights at 11 PM").

## 3. Society-Level Automations

The society's infrastructure also connects with resident smart devices for these automations:

* **Gate Entry:** Approved visitors trigger an automatic notification to your doorbell camera.
* **Power Outage Alert:** An automated push notification is sent during any scheduled maintenance outage.
* **Water Supply Schedule:** Smart valve control that syncs with the society's water distribution timer.
* **Emergency Lockdown:** In case of a security alert, all smart locks can be set to auto-lock via the app.

## 4. Cybersecurity Guidelines

1. Always use a **strong, unique password** for your smart home devices — never use the factory default.
2. Keep device firmware updated; the Society App will notify you when an update is available for integrated devices.
3. Use a **separate IoT Wi-Fi network** from your primary home network — the Society IT Helpdesk can assist with router configuration.
4. Do not share your Society App credentials with anyone.
5. Report any suspicious activity or unauthorized device access immediately to the **IT Helpdesk at Ext. 150**.
