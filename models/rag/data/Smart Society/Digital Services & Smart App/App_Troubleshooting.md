# 📱 Society Smart App: Troubleshooting Guide

A guide to resolving common issues with the official Resident Mobile Application (available on Android and iOS).

**App Version:** 2.8.1 | **Support Email:** support@smartsociety.pk | **IT Helpdesk:** Ext. 150

## 1. Login Issues

* **Forgotten Password:** Use the "Forgot Password" link on the login screen to receive an OTP via your registered mobile number.
* **Account Locked:** If you enter the wrong PIN 5 times, your account will be locked for 30 minutes for security. After 30 minutes, you may try again or call IT Helpdesk.
* **New Resident — No Account:** First-time users must register at the Admin Office or via **portal.smartsociety.pk** before they can log in to the mobile app.

## 2. Common Issues & Fixes

| Issue | Solution |
| :--- | :--- |
| **Bill not showing** | Refresh the 'Payments' tab or clear App Cache (Settings → App Info → Clear Cache) |
| **RFID tag not activating gate** | Ensure your maintenance dues are cleared; contact Admin if dues are paid |
| **QR code not scanning at gate** | Update the App to the latest version from Play Store / App Store |
| **Push notifications not arriving** | Go to Phone Settings → Notifications → Society App → Enable All |
| **App crashes on open** | Uninstall and reinstall the app; restore login with your CNIC and OTP |
| **Guest code not working** | Verify the code was generated for today's date; re-generate if expired |
| **Smart home device not syncing** | Toggle device offline/online in app; check home Wi-Fi connection |
| **Live bus tracking not loading** | Allow location permissions for the app; check internet connection |
| **Complaint not submitting** | Ensure you have attached an image if prompted; check file size (max 5 MB) |
| **Payment failed** | Verify card/account details; retry after 5 minutes; contact bank if recurring |

## 3. App Permissions Required

For full functionality, the Society App requires:

| Permission | Purpose |
| :--- | :--- |
| Camera | QR code scanning for visitor entry and parcel pickup |
| Location | School bus live tracking and gate notifications |
| Notifications | Bill reminders, visitor alerts, emergency announcements |
| Storage | Downloading receipts and documents |
| Contacts | (Optional) Auto-fill guest registration from contacts |

## 4. Updating the App

It is strongly recommended to keep the app updated:
1. Open Play Store or App Store.
2. Search "Smart Society Resident App."
3. Tap **Update** if available.
4. If the update fails, uninstall and reinstall — your data is stored on the server, not locally.

## 5. Reporting a Bug

If you encounter a bug not covered above:
1. Go to **App Menu → Help → Report a Bug**.
2. Describe the issue and attach a screenshot.
3. The IT team will respond within **2 working days**.
4. Alternatively, email **support@smartsociety.pk** with your house number and a description of the problem.
