# 🪪 Visitor Registration & Entry Policy

## 1. Purpose

To maintain the security and privacy of all residents, Smart Society enforces a mandatory visitor registration process at all entry points. No visitor may enter the society without following this procedure.

## 2. Types of Visitors

| Visitor Type | Entry Method | Valid Duration |
| :--- | :--- | :--- |
| Personal Guest (family/friends) | Guest Code via Society App or gate registration | Single day (expires midnight) |
| Service Worker (plumber, electrician, etc.) | Worker Entry Pass from Admin | Duration of job (max 48 hours) |
| Delivery Person | Package Drop-Off Lane | 15 minutes maximum |
| Estate Agent / Buyer | Pre-approved appointment slip | Duration of visit |
| Corporate / Official Visitor | Official ID + resident confirmation | Duration of meeting |

## 3. Guest Code System (via Society App)

1. Open the **Society App → Visitors → Generate Guest Code**.
2. Enter the guest's name and expected date/time of arrival.
3. A **6-digit Guest Code** is generated and valid for the specified date only.
4. Share the code with your guest. At the gate, the guard scans or enters the code to verify and grant entry.

## 4. Walk-In Guest Registration (Without Prior Code)

If a guest arrives without a pre-generated code:
1. The guard calls the resident's registered mobile number for verbal approval.
2. If the resident confirms, the guest's **CNIC number** is recorded in the gate register.
3. Entry is granted and a visitor pass is issued.
4. The pass must be worn visibly and returned at exit.

## 5. Domestic Workers & Regular Visitors

* Domestic workers who visit daily (cook, maid, driver) must be **pre-registered** at the Admin Office.
* Pre-registered workers receive a **Domestic Worker RFID Card** for gate access during approved hours.
* RFID cards are issued free for the first worker; Rs. 200 per additional card.

## 6. Overstay & Violations

| Situation | Action |
| :--- | :--- |
| Guest exceeds approved time | Guard notifies resident; extension approval required |
| Unregistered worker found on premises | Worker escorted out; Rs. 2,000 fine to resident |
| Repeated visitor policy violations by a resident | Formal warning from Admin Committee |

## 7. Overnight Guests

* Residents may host overnight guests without special permission for up to **7 consecutive nights**.
* Guests staying beyond 7 nights must be registered at the Admin Office (temporary resident record).
* Tenants subleasing a unit to an unregistered individual will face a **lease termination notice**.
