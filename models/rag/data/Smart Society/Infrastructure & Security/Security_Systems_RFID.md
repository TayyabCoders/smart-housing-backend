# 🛡️ Security Systems & RFID SOPs

## 1. RFID Vehicle Access System

Every resident vehicle must be registered and fitted with a society-issued RFID tag for automated gate entry.

| Detail | Information |
| :--- | :--- |
| RFID Tag Fee | Rs. 500 per tag (one-time) |
| Replacement Tag (lost/damaged) | Rs. 300 |
| Maximum Vehicles per Household | 3 |
| Tag Registration Office | Admin Office, Mon–Sat 9 AM – 5 PM |

### How RFID Gate Works
1. As your vehicle approaches the main gate, the RFID reader detects the tag at a range of up to 5 meters.
2. If the tag is valid and maintenance dues are current, the boom barrier lifts automatically.
3. If dues are overdue, the barrier does NOT open and a guard is alerted — the resident must visit the Admin Office to regularize.
4. **All RFID entries are time-stamped and logged** for security records.

### Temporary Vehicle Pass
* For vehicles not yet registered (new purchase, repair loan vehicle), a **Temporary Vehicle Pass** is issued at the gate.
* Maximum validity: 7 days. After 7 days, the RFID tag must be obtained.
* Guests' vehicles are issued a **Guest Entry Slip** (printed at the gate).

## 2. Biometric Access (Community Facilities)

| Location | System | Who Can Enter |
| :--- | :--- | :--- |
| Gym Entrance | RFID card tap | Active gym members |
| Swimming Pool Gate | RFID card tap | Registered residents |
| Server/Utility Room | Biometric fingerprint | Authorized staff only |
| Admin Office Back Area | Biometric + PIN | Admin staff only |

## 3. Patrol Security

* The society employs **32 trained security guards** operating in three 8-hour shifts.
* **4 armed guards** are stationed at the main gate around the clock.
* **Mobile patrol units** (2 vehicles) run random circuits every 45 minutes throughout the society.
* A **Security Control Room** (Ext. 911) monitors all CCTV feeds in real time and coordinates guard deployment.

## 4. CCTV Surveillance

* The society is under **24/7 CCTV monitoring** with 214 cameras.
* Footage is recorded and retained for **30 days** on encrypted local servers.
* To request video footage for an incident: submit a written application at the Admin Office.
* Approved requests are processed within **3 working days**.

## 5. Security Alert Levels

| Alert Level | Trigger | Response |
| :--- | :--- | :--- |
| Code Green | Normal operations | Standard patrol schedule |
| Code Yellow | Minor incident / suspicious person | Increased patrol; all guards on standby |
| Code Orange | Active intrusion or serious crime | All entry/exit gates locked; police called |
| Code Red | Immediate threat to life | Full lockdown; police + ambulance dispatched |

Residents are notified of Code Orange and Red via an **emergency broadcast on the Society App**.
